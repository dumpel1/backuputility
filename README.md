# 💾 Утилита мульти-резервного копирования (Web UI)

Высокотехнологичный Python-скрипт промышленного уровня, разработанный для динамического объединения нескольких произвольных исходных каталогов в единый защищенный ZIP-архив. Проект оснащен легковесным адаптивным **веб-интерфейсом** на базе Streamlit, автоматической системой ротации (очистки) архивов и интеллектуальной фильтрацией системного цифрового мусора.

---

## 🚀 Ключевые возможности

- **Мульти-выбор источников:** Динамическое добавление нескольких абсолютных путей к разным папкам в один общий структурированный архив.
- **Интеллектуальная изоляция мусора:** Автоматический обход дерева файлов с жестким игнорированием служебных артефактов разработки (`.git`, `__pycache__`, `venv`, `.idea`, `.vscode`).
- **Автоматическое управление ротацией:** Встроенный движок, отслеживающий время изменения файлов для удаления устаревших бэкапов по заданному пользователем лимиту дней.
- **Обработка крайних случаев (Edge-Cases):** Встроенная защита от циклической рекурсии файловой системы (запрет сохранения архива внутрь копируемой папки) и упреждающая проверка на пустоту каталогов через высокоэффективный `os.scandir`.
- **Современный Web UI:** Архитектура с разделением логики и представления (Model-View) для работы с утилитой прямо через браузер.

---

## 🛠️ Архитектура и технологии

- **Язык разработки:** Python 3.10+
- **Интерфейс (Frontend):** Streamlit (управление состоянием через `st.session_state`)
- **Базовые библиотеки:** `pathlib` (объектно-ориентированная работа с путями), `zipfile` (движок сжатия), `os` и `logging`.

Кодовая база строго соответствует принципам **MVC (Model-View-Controller)**. Вся логика манипуляции файлами, обхода каталогов и архивации полностью вынесена в модуль `backup_logic.py`, что обеспечивает масштабируемость кода и простоту покрытия юнит-тестами.

## 📦 Установка и настройка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd backuputility
   ```

2. **Установите необходимые зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

## 🏃 Запуск приложения

### Способ 1: Ярлык на Рабочем столе (Только для Windows)
Просто дважды кликните по файлу `runweb.bat` в корневой папке проекта. Он автоматически настроит окружение и развернет веб-сервер.

### Способ 2: Ручной запуск через терминал
Запустите системную обертку Streamlit напрямую из вашей командной строки:
```bash
python -m streamlit run app_web.py
```
После запуска перейдите в браузере по адресу `http://localhost:8501`.
